# GyLiber Algorithm Workbench

A collection of small programming practices implemented as reusable algorithms
and components rather than only as fixed solutions to individual exercises.

The exercises use narrowly specified academic problems as concrete
specializations and tests of the underlying reusable implementations.

## Languages

- ANSI C90
- Java
- JavaScript
- TypeScript

## Repository Structure

```text
c90/          ANSI C90 practices
java/         Java practices
javascript/   JavaScript practices
typescript/   TypeScript practices
```

Each practice is intended to be small, understandable, documented, and
independently testable.

## Development Philosophy

The repository emphasizes:

- algorithms independent of unnecessary data representation assumptions;
- reusable interfaces and components;
- simple correct implementations;
- practical testing through concrete problem requirements;
- documentation that supports both collaboration and later recall.

See `DESIGN.md` for the repository design.
